# UI 优化验收记录（2026-09-05，待用户预览）

## 交付边界

- 保持 Next.js + React；没有添加运行时 UI 依赖，没有替换框架。
- 本轮没有 commit、push、release 或部署。线上 bangmio.site 仍是原版。
- 真实运营基线来自用户已登录的线上页面：在看列表、已收藏条目、小组首页及小组帖子。只读浏览，没有修改真实评分、收藏、观看进度或发布帖子。
- 新样式只在本地预览；登录态几何回归使用隔离的合成账号，相关请求拦截，不代表真实账号的线上写入验收。

## 已完成

1. 评分：去掉无意义的横向滚动，十星使用可收缩网格；窄屏独立一行，不减少评分选项。
2. 对齐：详情头部使用命名网格区域；观看进度是独立的整行卡片，不再嵌套撑高收藏盒；桌面海报与收藏盒底边保持一致。
3. 社区：讨论主栏与小组目录分列；统一标题、正文、元信息、分隔线、按钮、输入区和移动端换行。降低阴影和装饰性文案，保留粉色品牌色，但使用更克制的强调色。
4. 状态：明确区分加载、无数据、失败、访客和未绑定；绑定按钮直接进入绑定页，登录保留返回路径，发帖失败保留草稿。
5. 数据请求：小组搜索取消旧请求并阻止乱序覆盖；退出账号后丢弃旧关注列表响应；移除关注列表逐个拉取详情的 N+1 请求。缺失成员数不再伪装成零。
6. 线上发现的正文问题：服务端新增明确的 main_post 字段，保留旧 replies 契约；React 页面只把明确识别的首帖移到正文，不猜测首条回复就是楼主。展示原始楼层和“已加载”回复数量。
7. 清理不再匹配 DOM 的收藏盒嵌套样式；增加海报、小组头像失败回退。
